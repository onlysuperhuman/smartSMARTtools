Smart SMART Meeting Generator

Create ready-to-share SMART Recovery meeting attendance verification PDFs for one or more participants.

Private by design: this page works entirely on your computer. Participant names, meeting dates, and finished PDFs are not sent anywhere.

1. Your facilitator details

These details appear on every verification form in the batch.

For example: “Community Zoom,” “Monday Evening,” or a physical location.
Can be added automatically to the confidentiality wording.
Participant names and meeting dates are never saved by this tool.

2. Choose the verification wording

Start with a suggested option, then edit the final text before creating the PDFs.

Choose any blocks you want to include

Custom blocks are kept on this computer only when “Remember my facilitator settings” is checked.
This editor is the final say: make any changes here before generating. Text wraps onto separate form lines for readability.

3. Add the meeting and participants

Used for every pasted name and printed in both date locations.
PDF filenames use first name + last initial by default.
One person per line. Optional format: Full Name | Filename Name.
or choose a CSV
Headers: full_name, optional file_name, optional date. If the CSV contains multiple dates, the tool creates one ZIP for each date.

Your downloads are ready

Each ZIP contains the PDFs for one meeting date. Creating them again replaces these links with a fresh set.
How does privacy work?

Everything runs inside this HTML file. The tool does not upload names, dates, settings, or PDFs. If you choose to remember settings, only your facilitator details, preferred wording, and custom wording blocks are stored in this browser. Participant names and dates are not stored.
