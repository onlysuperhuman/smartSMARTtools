# smartSMARTtools

Small, free tools that make life easier for SMART Recovery meeting facilitators.

Built by a facilitator, for facilitators. Each tool does one job, works in a browser, and needs no account.

## Tools

| Tool | What it does |
|---|---|
| [Smart SMART Meeting Generator](meeting-verification-generator/) | Create meeting attendance verification PDFs for one or more participants while keeping their information private and local on your computer. 
Built on Smart Recovery USA Volunteer HQ verification form [https://volunteerhq.smartrecovery.org/wp-content/uploads/2021/03/Zoom-Meeting-Attendance-Verification-Form.pdf](https://volunteerhq.smartrecovery.org/wp-content/uploads/2021/03/Zoom-Meeting-Attendance-Verification-Form.pdf) |

## Use one

Open the tool's folder and follow its short readme. Most tools are a single file you can open in any browser.

## Privacy

These tools don't collect or store participant data. Please never commit names, shares, or anything from a meeting to this repo.

## Contribute

Got an idea, a bug, or a tool of your own? Open an issue or a pull request. Facilitator feedback is the most useful kind.
